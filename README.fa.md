## برای چه کسانی است؟

«نوبت» برای یک مطب یا گروه مشاوره‌ی کوچک ساخته شده که **یک هماهنگ‌کننده همه‌ی جلسه‌ها را** تلفنی یا حضوری ثبت می‌کند—و هر همکار فقط برنامه‌ی خودش را می‌بیند.

مناسب وقتی تقویم خصوصی روی سرور خودتان می‌خواهید، نه یک سرویس ابری دیگر.

## نوبت چه کار می‌کند؟

- **تقویم هماهنگ‌کننده** — نمای ماهانه‌ی شمسی از نوبت‌های همه؛ ثبت، جابه‌جایی یا لغو از یک جا. هر نوبت شامل حروف اول نام مراجع، تاریخ، ساعت، مدت جلسه، نام همکار و یک یادداشت خصوصی اختیاری است.
- **نمای همکار** — هر همکار با حساب خودش وارد می‌شود و **فقط نوبت‌های خودش** را همراه با یادداشت‌ها می‌بیند.
- **اعلان روی گوشی** — هنگام ثبت، جابه‌جایی یا لغو نوبت؛ و هر شب فهرست جلسه‌های فردا.
- **نصب مثل برنامه (PWA)** — از مرورگر به صفحه‌ی اصلی گوشی اضافه کنید.

## ظاهر و پوسته‌ها

رابط نئومورفیسم با **حالت روشن و تیره** و پالت‌های رنگی قابل تعویض (پیش‌فرض **یارو نارنجی**، به‌علاوه‌ی **فیروزه‌ای**). میزبان—و کاربر—می‌توانند ظاهر مناسب مطب را انتخاب کنند؛ ترجیح در مرورگر ذخیره می‌شود.

## حریم خصوصی از پایه

برای محیط‌های حساس طراحی شده و سطح داده را کوچک نگه می‌دارد:

- **کاملاً روی سرور خودتان.** بدون آمارگیری ابری، بدون فروشنده‌ی هوش مصنوعی. اعلان‌ها از سرور [ntfy](https://ntfy.sh)ی خودتان فرستاده می‌شوند.
- **کمترین داده.** حروف اول نام مراجع، زمان، و یادداشت اختیاری. نام کامل و شماره تلفن لازم نیست.
- **ایمن برای صفحه‌ی قفل.** اعلان‌ها یادداشت خصوصی را نشان نمی‌دهند—فقط حروف اول و زمان.
- **دسترسی محدود.** هر همکار فقط نوبت‌های خودش را می‌بیند.
- **همه‌چیز در یک فایل SQLite** — پشتیبان‌گیری و انتقال به سرور دیگر ساده است.
- تنظیمات امن پیش‌فرض: هش رمز با scrypt، محافظت CSRF، سیاست امنیتی سخت‌گیرانه‌ی محتوا (CSP)، محدودیت تلاش ورود، و سرویس‌ورکری که صفحه‌های نوبت را روی دستگاه ذخیره نمی‌کند.

## شروع سریع

به یک سرور لینوکسی با Docker، یک دامنه (دو زیردامنه) و پراکسی معکوس با HTTPS مثل Caddy نیاز دارید.

</div>

```bash
git clone https://github.com/PouryaFA81/Nobat.git nobat
cd nobat
cp .env.example .env        # سپس آن را ویرایش کنید
docker compose up -d --build
```

راهنمای کامل—شامل اعلان‌ها، اولین حساب و پشتیبان‌گیری—در **[docs/INSTALL.fa.md](docs/INSTALL.fa.md)** است.

## تنظیمات

همه‌ی تنظیمات در فایل `.env` هستند:

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| `SECRET_KEY` | *(الزامی)* | رشته‌ی تصادفی برای کوکی ورود. با `openssl rand -hex 32` بسازید. |
| `NTFY_TOKEN` | | توکنی که پنل با آن اعلان می‌فرستد. |
| `BASE_URL` | | آدرس عمومی پنل، مثلاً `https://nobat.example.com` |
| `NTFY_PUBLIC_URL` | | آدرس عمومی سرور اعلان |
| `TIMEZONE` | `Asia/Tehran` | منطقه‌ی زمانی همه‌ی تاریخ‌ها و ساعت‌ها |
| `REMINDER_HOUR` | `20` | ساعت ارسال یادآوری «جلسه‌های فردا» |
| `STAFF_LABEL` | `مشاور` | عنوانی که پنل برای همکاران به کار می‌برد، مثلاً `پزشک` یا `درمانگر` |
| `STAFF_LABEL_PLURAL` | عنوان + «ان» | شکل جمع، اگر پیش‌فرض درست نبود |
| `SOURCE_URL` | همین مخزن | لینک کد منبع در پایین صفحه (بخش [مجوز](#مجوز) را ببینید) |
| `COOKIE_SECURE` | `1` | فقط برای آزمایش محلی بدون HTTPS روی `0` بگذارید. |

## پشتیبانی نصب

سرور ندارید یا ترجیح می‌دهید نصب را بسپارید؟ نصب و نگهداری را می‌توان به‌صورت خدمت پولی هماهنگ کرد.

👉 **[ثبت درخواست نصب](https://github.com/PouryaFA81/Nobat/issues/new?template=setup_request.yml)**: نیازتان را بنویسید، ولی اطلاعات تماس خصوصی را عمومی نگذارید. نگهدارنده‌ی پروژه در همان صفحه پاسخ می‌دهد تا گفت‌وگوی خصوصی هماهنگ شود.
