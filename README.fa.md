## نوبت چه کار می‌کند؟

«نوبت» برای یک گروه کوچک ساخته شده، مثلاً چند مشاور یا پزشک، که **یک نفر هماهنگ‌کننده همه‌ی نوبت‌ها را** تلفنی یا حضوری ثبت می‌کند.

- **هماهنگ‌کننده** وارد پنل می‌شود، تقویم ماهانه‌ی شمسیِ نوبت‌های همه را می‌بیند و نوبت ثبت، جابه‌جا یا لغو می‌کند.
  هر نوبت شامل حروف اول نام مراجع، تاریخ، ساعت، مدت جلسه، نام همکار و یک یادداشت خصوصی اختیاری است.
- **هر همکار** با حساب خودش وارد می‌شود و **فقط نوبت‌های خودش** را همراه با یادداشت‌ها می‌بیند.
- **اعلان روی گوشی**: وقتی نوبتی برای همکار ثبت، جابه‌جا یا لغو شود، و هر شب فهرست جلسه‌های فردا.
- **نصب روی گوشی** مثل یک برنامه (PWA): از مرورگر، گزینه‌ی «افزودن به صفحه‌ی اصلی» را بزنید.

## حریم خصوصی از پایه

- **کاملاً روی سرور خودتان**: بدون سرویس ابری، بدون آمارگیری، بدون هوش مصنوعی. اعلان‌ها از سرور [ntfy](https://ntfy.sh)ی خودتان فرستاده می‌شوند.
- **کمترین داده**: فقط حروف اول نام مراجع، زمان نوبت و یک یادداشت اختیاری. نیازی به نام کامل یا شماره تلفن نیست.
- **یادداشت‌ها در اعلان نمی‌آیند**: اعلان فقط حروف اول نام و زمان را نشان می‌دهد، چون روی صفحه‌ی قفل گوشی دیده می‌شود.
- **هر همکار فقط نوبت‌های خودش را می‌بیند.**
- **همه‌چیز در یک فایل SQLite** است؛ پشتیبان‌گیری و انتقال به سرور دیگر ساده است.
- تنظیمات امن پیش‌فرض: رمزهای هش‌شده (scrypt)، محافظت CSRF، سیاست امنیتی سخت‌گیرانه‌ی محتوا (CSP)، محدودیت تلاش ورود،
  و سرویس‌ورکری که هیچ‌وقت صفحه‌های نوبت را روی گوشی ذخیره نمی‌کند.

## شروع سریع

به یک سرور لینوکسی با Docker، یک دامنه (دو زیردامنه) و یک پراکسی معکوس با HTTPS مثل Caddy نیاز دارید.

</div>

```bash
git clone https://github.com/PouryaFA81/Nobat.git nobat
cd nobat
cp .env.example .env        # سپس آن را ویرایش کنید
docker compose up -d --build
```

راهنمای کامل و مرحله‌به‌مرحله، شامل اعلان‌ها، ساخت اولین حساب و پشتیبان‌گیری، در **[docs/INSTALL.fa.md](docs/INSTALL.fa.md)** است.

## تنظیمات

همه‌ی تنظیمات در فایل `.env` هستند:

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| `SECRET_KEY` | *(الزامی)* | رشته‌ی تصادفی برای کوکی ورود. با `openssl rand -hex 32` بسازید. |
| `NTFY_TOKEN` | | توکنی که پنل با آن اعلان می‌فرستد. |
| `BASE_URL` | | آدرس عمومی پنل، مثلاً `https://nobat.example.com` |
| `NTFY_PUBLIC_URL` | | آدرس عمومی سرور اعلان |
| `TIMEZONE` | `Asia/Tehran` | منطقه‌ی زمانی همه‌ی تاریخ‌ها و ساعت‌ها |
| `REMINDER_HOUR` | `20` | ساعت ارسال یادآوری «جلسه‌های فردا» |
| `STAFF_LABEL` | `مشاور` | عنوانی که پنل برای همکاران به کار می‌برد، مثلاً `پزشک` یا `درمانگر` |
| `STAFF_LABEL_PLURAL` | عنوان + «ان» | شکل جمع، اگر پیش‌فرض درست نبود |
| `SOURCE_URL` | همین مخزن | لینک کد منبع در پایین صفحه (بخش [مجوز](#مجوز) را ببینید) |
| `COOKIE_SECURE` | `1` | فقط برای آزمایش محلی بدون HTTPS روی `0` بگذارید. |

## پشتیبانی نصب

سرور ندارید یا ترجیح می‌دهید نصب را به کس دیگری بسپارید؟ نصب و نگهداری را می‌توان به‌صورت خدمت پولی هماهنگ کرد.

👉 **[ثبت درخواست نصب](https://github.com/PouryaFA81/Nobat/issues/new?template=setup_request.yml)**: نیازتان را بنویسید، ولی اطلاعات تماس خصوصی را عمومی منتشر نکنید. نگهدارنده‌ی پروژه در همان صفحه پاسخ می‌دهد تا گفت‌وگوی خصوصی هماهنگ شود.
